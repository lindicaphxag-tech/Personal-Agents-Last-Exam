# Event-equivalence walking search (research reference, not integrated App)

The earlier exact-time fallback retains different arrival times. This version computes a finite temporal partition: seed each node with the horizon endpoints and local edge availability endpoints; propagate each destination boundary backward by the edge duration until closed under all transitions. Inside a cell, availability of each outgoing edge is constant and its translated arrival time stays in the same destination cell (or lies outside the horizon). Thus for two labels at the same node and cell, the earlier label with no greater walking distance can execute the same feasible continuation no later and with no greater cost. Induction on the continuation establishes safe dominance. Static graphs need no partition; if the partition cap is reached, discard the partial partition and use exact-time dominance instead. This is a finite-state abstraction of an integer-time bounded resource-constrained graph, not a claim of general theoretical novelty.

Zero-duration and zero-distance edges are supported. Equal-state dominance eliminates zero-cost cycles; the bounded integer state space is finite. Queue ordering is lexicographic in time and distance, and the first active destination popped is optimal. Reverse relaxed time/distance bounds are admissible; no implicit waiting. State cap returns incomplete, never infeasible. All tests use safe integer quantities. Partition construction can be expensive (especially with small positive durations on cyclic networks); its cap is a guard, not a scalability theorem.

Adapter: walking-only, place endpoints, step-free edges, pinned synthetic seed. It reproduces the facilityAt entry-time semantics of Hopline network.cjs blob be3fc5fdce4a89da4e8541871ac7bef7306c2388 in an isolated reference function. It separates estimated restoration from confirmed availability by a caller flag, default false. This is not the production runtime, does not validate a general seed, does not handle transit, stop endpoints, historical trip updates, continuous occupancy, or native itinerary serialization. Do not replace Hopline App with it. The original #110 task and #171 branch remain unchanged. The reference is evaluated on the exact pinned seed, plus explicit synthetic modifications to the facility history.

Validation: 9 assertion groups, 1600 random instances against independent full discrete-state reachability; three algorithms per instance (exact time, event, partition cap fallback). 386 feasible instances. This selected synthetic case illustrates potential compression; it is not representative runtime evidence. Five pinned-seed adapter checks passed.
