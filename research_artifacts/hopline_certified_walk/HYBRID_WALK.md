# Bounded hybrid walking search — independent research candidate

A bounded exact-label probe attempts to finish first. Only a certified optimal or infeasible result is returned; if incomplete, restart with exact delta-interval propagation. The default probe cap is 128 generated labels, not a bound on all its preprocessing or operations. This is a sequential portfolio, not a mid-search transfer or joint memory budget: limits apply per phase; the second phase does not inherit labels. It avoids changing any approved PALE task or shared App.

The symbolic engine stores the reached union and pending newly reached intervals per (node, exact cost). For each update, subtract previously reached times, union the remainder into pending, then propagate each newly reached integer time once per outgoing edge when dequeued (overlapping input windows can cause redundant attempted inserts). No waiting, fixed nonnegative integer duration/cost, finite integer horizon and entry-time windows. Reverse relaxed shortest duration d and distance w are separately admissible. Remove a candidate if its budget or deadline cannot be met. Given a feasible incumbent (T,C), a state at time t and cost c can only improve it if t+d<T or t+d=T and c+w<C. Keep only the portion of an interval satisfying this necessary condition. Earlier reached states are retained for witness reconstruction. The target is absorbing. Every inserted time has an actual predecessor, and pruning cannot remove a strictly better feasible continuation: the incumbent is itself reached and the lower bounds apply to any continuation. Monotone finite union growth and fair queue processing imply termination absent a cap; the final incumbent is lexicographically optimal if the queue drains. Reverse search reconstructs a witness from reached states, with visited triples to handle zero-cost cycles. Work or storage exhaustion returns incomplete, never infeasible. The cap counts selected operations including reverse scans, interval scans, transforms, and witness scans; not every JS operation or allocated byte. The probe separately uses the earlier solver's label cap.

Results: 10 assertion groups, 2400 new random graphs, 739 feasible, 1193 dynamic, 939 with zero-time zero-cost edges. Four algorithms per graph (delta, default hybrid, forced fallback, previous full interval) matched independent explicit-state reachability; witnesses replayed. Default fallback count 0; forced fallback count 761. Interval transforms 19870 before and 4344 after on random graphs. Work counters differ: the new counter includes scans and reverse preprocessing, old one does not. Five deliberately structured layered stress cases and four pinned fixture cases. This synthetic layered family favors contiguous interval sets. Not a runtime speedup claim. The exact-label probe returns all four pinned fixture results directly; delta remains available for large instances. No guarantee of universal performance improvement, no novel general theorem claim. No actual App or Node wrapper CI; exact functions and pinned dependencies were executed in the JS environment. The adapter inherits the prior walking-only restrictions; no general transit or production integration. Run node test_hybrid_walk.cjs. No upstream merge or authorship claimed.
