# Certified bounded-walking reference — Hopline #171 research candidate

This author-side solver addresses the independently reproduced bounded-walking counterexample at Hopline commit 1d7fecfb8b12bc4c85b02f776cae651b9f1b6dab (planner blob 43ef9a8790aa737348311e8f7f4d10d74874e672). It is NOT the shared Hopline App, an integrated patch, or a LifePack runner. It does not change the approved #110 task or the upstream #171 branch.

Contract: finite directed graph, integer ticks, strictly positive edge duration, nonnegative integer walking distance, finite deadline and distance budget, no waiting, optional fixed entry-time availability windows. Availability is a caller-supplied known model, not inferred from real facilities. This implementation does not model transit rides, transfer limits, cancellation, forecast validity, facility use throughout traversal, or the production API's arrive_by behavior. Zero-time production access links need separate handling before integration.

Proof: in a static graph, label (t,w) dominates (t',w') if t<=t' and w<=w'; each identical continuation remains feasible and no worse. In a dynamic no-wait graph, restrict dominance to equal arrival time; an earlier label can be unable to take an edge that opens later. Positive durations and finite deadline imply finitely many paths. Process labels by ascending arrival time then walking distance, preserving immutable predecessor links. The first active destination popped is optimal lexicographically; if the queue empties, no feasible path exists. The reverse shortest-duration and shortest-distance bounds ignore availability and are admissible separately, even when different paths minimize each. A label cap returns incomplete, never infeasible. This is a scoped application of established resource-constrained shortest-path methods, not a new general theorem.

The pinned synthetic #110 walking network (seed blob 57651d4ff6860b22394b9c1e92fbeaa3510e820a) is copied verbatim from the fork at 2c86829. The test transforms lengths exactly as the previously published source-level counterexample, includes only step-free walking edges and uses static service before closure. Original upstream search was previously observed to return no destination label at 350 and 375m; this reference produces 870s/350m at both. At 400m it returns 330s/400m. 349m infeasible in the modified reference. It does not run upstream search anew in this test.

Validation: 8 deterministic assertion groups, 1200 randomized graph instances (including cyclic and time-dependent), 517 feasible. Exhaustive finite path enumeration is an independent reference. Both pruned and unpruned solvers matched optimal arrival and distance, and every returned witness was replayed. Reverse-bound pruning reduced expanded labels from 3167 to 1556 across the selected synthetic cases, not a measured runtime speedup. 535 instances contain time windows.
